# Results index

This directory contains the saved outputs from the notebook workflow. Summary tables, JSON configuration/manifest files, and aggregate plots are kept for review.

- `test_metrics.json`, `test_model_comparison.csv`, and `training_history.json` — classifier evaluation and training summaries.
- `gradcam/` — aggregate Grad-CAM figures; per-image `heatmaps/` and `overlays/` are regenerated by Notebook 3 and ignored by Git.
- `trust_uncertainty/` — calibration, trust, and uncertainty summaries and plots.
- `rag/` — retrieval evaluation, source/chunk metadata, and compact index artifacts.
- `llm_explanations/` — saved explanation examples and the 30-sample run.
- `human_feedback/` — aggregate review/evaluation summaries. Raw feedback records and queues are excluded by `.gitignore`.
- `final_integration/` — integrated pipeline summaries, demo outputs, and representative plots.

Some results are run-specific. Re-run the relevant notebook to reproduce them with a newly configured dataset and model checkpoint.
